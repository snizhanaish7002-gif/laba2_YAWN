Сторінки Головна, Події, Приєднатися, Питання-та-відповіді, Контакти-&-партнерство мають робоче меню навігації. На всіх сторінках додано `<header>` (шапка сайту), `<nav>` (навігаційне меню), `<main>` (основний унікальний контент сторінки) та `<footer>` (підвал із контактною/додатковою інформацією).

Також на сторінках використано елементи (щонайменше по одному разу) заголовку `<hX>` для ієрархії тексту, абзаци `<p>` для текстових блоків, списки `<ul>/<ol>` для переліків, посилання `<a>` з атрибутом href для переходів, зображення `<img>` з атрибутом alt  для візуального контенту та текстового опису, а також додано форму <form> для введення даних користувачем.
